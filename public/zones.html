🗂️ Zone Management
Zones are fully isolated — each zone's data lives in its own Firestore path
👑 How Zones Work — Same App, Fully Isolated
① Create zones below — each zone gets a unique Firestore path zones/ZONE_ID/...
② Create users and assign them to a zone (in 👥 Users page)
③ When a user logs in, they only see their own zone's data — orders, outlets, collections, routes, everything
④ You (Owner) see all zones from the dashboard with a cross-zone summary
