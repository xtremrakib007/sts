# STFM Sales — Android APK Build Guide

## Project Structure
```
stfm-capacitor/
├── capacitor.config.json   ← App config
├── package.json
├── www/                    ← Your web app (deployed here)
│   ├── index.html
│   ├── app.css
│   └── js/
│       └── app.min.js
└── android/                ← Generated by Capacitor (after step 3)
```

---

## Prerequisites (install once)

1. **Node.js 18+** → https://nodejs.org
2. **Android Studio** → https://developer.android.com/studio
   - Inside Android Studio: SDK Manager → install Android SDK 34 + Build Tools 34
3. **Java JDK 17** → https://adoptium.net
4. Set environment variables:
   ```
   ANDROID_HOME = C:\Users\YourName\AppData\Local\Android\Sdk   (Windows)
   ANDROID_HOME = ~/Library/Android/sdk                          (Mac)
   ```

---

## Build Steps

### Step 1 — Install dependencies
```bash
cd stfm-capacitor
npm install
```

### Step 2 — Add Android platform
```bash
npx cap add android
```

### Step 3 — Sync web files to Android
```bash
npx cap sync android
```

### Step 4 — Open in Android Studio
```bash
npx cap open android
```

---

## Build Signed APK (Release)

In Android Studio:

1. **Build** → **Generate Signed Bundle/APK**
2. Select **APK**
3. Key store path: browse to `stfm-release.jks`
4. Key store password: *(your keystore password)*
5. Key alias: `stfm`
6. Key password: *(your key password)*
7. Select **release**
8. Click **Finish**

APK output: `android/app/release/app-release.apk`

---

## After Every Code Change

When you update `index.html`, `app.css`, or `js/app.min.js`:

```bash
npx cap sync android
```

Then rebuild APK in Android Studio.

## Permissions Required

Already configured in AndroidManifest.xml:
- `INTERNET` — Firebase connection
- `CAMERA` — Selfie check-in / outlet photos
- `ACCESS_FINE_LOCATION` — GPS tracking
- `ACCESS_COARSE_LOCATION` — GPS fallback
- `READ_EXTERNAL_STORAGE` — Photo uploads
- `WRITE_EXTERNAL_STORAGE` — Photo saving
- `RECEIVE_BOOT_COMPLETED` — Background sync
- `VIBRATE` — Notifications

---

## FCM Push Notifications

Your app uses FCM. For push notifications in the APK:
1. Download `google-services.json` from Firebase Console → Project Settings
2. Place it at: `android/app/google-services.json`
3. Run `npx cap sync android` again

---

## Troubleshooting

**"SDK not found"** → Set ANDROID_HOME environment variable

**"Gradle sync failed"** → File → Sync Project with Gradle Files in Android Studio

**Camera not working on device** → Make sure you granted camera permission when prompted

**Firebase connection fails** → Check internet permission is in manifest (already done)
